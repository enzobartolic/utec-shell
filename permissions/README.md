# permissions

Scripts sobre permisos en Linux.

## 0-iam_betty
Script que cambia el usuario actual a `betty`.

## 1-who_am_i
Script que imprime el nombre de usuario efectivo del usuario actual.

## 2-groups
Script que imprime todos los grupos del usuario actual.

## 3-new_owner
Script que cambia el propietario del archivo `hello` al usuario `betty`.

## 4-empty
Script que crea un archivo vacío llamado `hello`.

## 5-execute
Script que añade permiso de ejecución al propietario del archivo `hello`.

## 6-multiple_permissions
Script que añade permiso de ejecución al propietario y al grupo, y de lectura a otros, al archivo `hello`.

## 7-everybody
Script que añade permiso de ejecución al propietario, grupo y otros, al archivo `hello`.

## 8-James_Bond
Script que establece los permisos de `hello` en 007 (sin permisos para propietario y grupo, todos los permisos para otros).

## 9-John_Doe
Script que establece el modo de `hello` en 753.
